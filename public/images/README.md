# Image placeholders

Drop your real images here using the filenames below. The site references
these paths from `src/data/profile.js` and gracefully falls back to a
stylised placeholder if a file is missing — nothing will break while you're
still collecting them.

| File name | What it is | Suggested size / format |
|---|---|---|
| `avatar.png` | Your headshot / avatar shown on the About platform | Square, ≥ 512×512, PNG or JPG |
| `medal-hust.png` | Reference photo of your HUST gold medal | For reference only — the on-screen medal is procedural 3D |
| `scholarship-2024-2.png` | Certificate for semester 2024-2 | 4:3 landscape, ≥ 1024 px wide |
| `scholarship-2025-1.png` | Certificate for semester 2025-1 | same |
| `scholarship-2025-2.png` | Certificate for semester 2025-2 | same |

If you want to add more (e.g. company logos, project screenshots) drop them
here too and reference them from the relevant file in `src/data/`.

Tip: for small photos, run them through a compressor like
[squoosh.app](https://squoosh.app) — 200-400 KB is a good ceiling.
